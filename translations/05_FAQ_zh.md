# 常见问题（FAQ）

> 原文来源：https://themodernsoftware.dev 站点结构化数据（`sources/course_source_en.md`，FAQ 共 7 条）
> 抓取日期：2026-09-28 ｜ 全部 7 条问答已逐条翻译，未删减。

---

### 1. 本课程会使用哪些编程语言？

课程本身与编程语言无关，聚焦于能跨语言通用的工具与实践。不过示例主要使用 **Python**、**JavaScript**，在合适的地方也会用到一些系统编程语言。重点在于理解现代开发实践，而不是精通某一门具体语言。

### 2. 我需要事先具备 Claude Code 等 AI 工具的使用经验吗？

不需要。课程会从基础讲起，逐步过渡到更高级的用法。但**扎实的编程基础（CS111 及以上）是必需的**。

### 3. 这门课会取代传统的软件工程课程吗？

不会。本课程是对传统软件工程课程的**补充**：它假设你已经具备软件工程基础知识，并在此基础上引入当代实践，聚焦现代工具与 AI 辅助开发。

### 4. 这门课的时间投入大概是多少？

预计每周约 **10–12 小时**，包含讲座、作业与项目工作。课程强调动手实践，需要留出时间试验新工具与新技术。

### 5. 有特殊的软硬件要求吗？

学生需要一台能够运行现代开发工具的电脑。部分云服务可能需要订阅（如 Claude Code 等），课程会尽可能提供访问权限或替代方案。使用云端工具需要稳定的网络连接。

### 6. 课程内容的时效性如何？

课程内容刻意保持**高度时效**，每周都会更新，以反映 AI 辅助开发领域快速演进的面貌。来自头部公司的客座讲者会确保学生了解到最新的行业实践与新兴工具。

### 7. 我可以旁听（audit）这门课吗？

我们接受斯坦福学生与教职员工的旁听申请。旁听者可以参加全部讲座，但我们**无法批改作业，也不能为期末项目提供指导**。

## 翻译备注

- 第 2 条的“CS111 及以上”指斯坦福课程编号体系，其他学校的读者可对应理解为“数据结构与算法级别及以上的编程训练”。
- 第 5 条提到的 Claude Code 订阅，在本校语境下由学校（SUNet ID）统一提供访问权限；非斯坦福读者需自行确认账号来源。
- 原文使用第二人称 "you"，中文统一处理为“你/学生”，不改变语义。
