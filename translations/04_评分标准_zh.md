# 评分标准（Grading）

> 原文来源：https://themodernsoftware.dev 站点结构化数据（`sources/site_data.json`，渲染见 `sources/course_source_en.md`）
> 抓取日期：2026-09-28
> 说明：站点数据中存在**两套**评分构成，bundle 本身未标注年份归属。下表按页面顺序与内容特征给出推断，**年份归属属于推断，未获一手确证**。

---

## 方案 A（3 项构成）

| 评分项 | 占比 |
| --- | --- |
| Final Project（期末项目） | 80% |
| Weekly Assignments（每周作业） | 15% |
| Class Participation（课堂参与） | 5% |
| **合计** | **100%** |

**推断归属**：更可能对应 Fall 2025。理由：该构成把权重高度集中在期末项目（80%），与 Fall 2025 大纲“以期末项目为主、作业为辅”的安排一致。

---

## 方案 B（4 项构成）

| 评分项 | 占比 |
| --- | --- |
| Final Project（期末项目） | 50% |
| Open Source Contributions（开源贡献） | 30% |
| Weekly Assignments（每周作业） | 15% |
| Class Participation（课堂参与） | 5% |
| **合计** | **100%** |

**推断归属**：更可能对应 Fall 2026。理由：新增“开源贡献 30%”独立评分项，且当前页面把期末项目权重下调至 50%，与 Fall 2026“开源伙伴 + 软件工厂”的课程定位一致（页面列出多家开源伙伴项目）。

---

## 复核提示（供人工校对）

1. 两套构成的年份归属建议在开学第一周以课程 syllabus PDF / Canvas 页面为准复核。
2. 若两套构成属于同一学期的不同版本（例如初版与修订版），则应以当前学期实际执行的版本为准。
3. 评分项英文原名保留在上表中，便于与国际学生、助教核对。
