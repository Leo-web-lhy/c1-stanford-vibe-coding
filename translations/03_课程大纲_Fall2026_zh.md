## 第 1 周：编码智能体的内部机理
**主题**：LLM 究竟是什么，以及智能体循环（agent loop）在底层长什么样 ｜ 核心工具集（read / write / edit / bash）与任务如何流经它们 ｜ 生产级编码智能体如何组织其系统提示与工具定义

**阅读材料**：
- 构建一个编码智能体 → https://youtube.com/watch?v=s7ZzkdvCMDY

**课程安排**：
- **周二 9/22**：课程介绍 + 用 200 行代码实现 Claude Code ｜ 幻灯片：https://docs.google.com/presentation/d/1uztIhjHAG6O_9QOD1N_3wdhwhABml1fANXEN2dGwdbg/edit?usp=drive_link ｜ 完成版代码：https://drive.google.com/file/d/1DxKa_autBOu9s8DvItodgUAwH_pBg7aR/view?usp=drive_link
- **周四 9/24**：最先进的编码智能体是如何设计的——深入剖析定义该智能体的系统提示 ｜ 幻灯片：https://docs.google.com/presentation/d/1RZu-p18Qybbgm8WVP2RH04ESc4Bn377B-T9j5-TBFdQ/edit?usp=drive_link ｜ 提示词集：https://drive.google.com/drive/folders/1c6_atVW0RrqEBWsNIscG2KNwCiuPxWQG?usp=drive_link

## 第 2 周：高级上下文工程
**主题**：高级提示技巧，以及各技巧的适用场景 ｜ RePPIT（研究、提案、计划、实现、测试）与规格驱动开发 ｜ MCP 基础：服务器、客户端、工具与传输 ｜ 面向智能体易用性（ergonomics）的工具设计

**课程安排**：
- **周二 9/29**：高级提示 + 智能体式开发框架（RePPIT、规格驱动开发）
- **周四 10/1**：MCP 与工具调用完整导论（理论、配置与高级工具设计）
